# Third-party services

The local dashboard communicates with GitHub for authentication-backed API access, repository and PR data, user-requested changes, and extension release/update information. Requests go from your machine to GitHub. The user's existing GitHub access limits what the dashboard can read and change. GitHub also hosts the project and its issue tracker; information posted to public issues is public.

No separate hosting, analytics, billing or AI service is required by the local CLI. Browser assets are served locally. See [GitHub’s privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement), the [local privacy policy](PRIVACY.md), and the [historical hosted-service disclosures](https://github.com/shiqicao/gh-pull/blob/v1.17.0/THIRD_PARTY_SERVICES.md).
